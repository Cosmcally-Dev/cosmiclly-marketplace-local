## Phase 2 — FeaturedAdvisorsSection Scroll Arrow State

### Goal
Make the left/right carousel arrow buttons appear dimmed (disabled) when they reach the start or end of the scroll list, and active otherwise.

### `src/components/home/FeaturedAdvisorsSection.tsx`

**Imports**
- Added `useState` and `useCallback` to the React import

**State**
- `canScrollLeft` — `boolean`, starts `false` (at the start, left arrow is disabled)
- `canScrollRight` — `boolean`, starts `true` (content extends to the right on load)

**Logic**
- Added `updateScrollState` callback — reads `scrollLeft`, `clientWidth`, and `scrollWidth` from the scroll container ref to determine whether scrolling is possible in each direction

**Scroll Container**
- Added `onScroll={updateScrollState}` to the `<div ref={scrollRef}>` so state updates on every scroll event

**Buttons**
- Left button: `disabled={!canScrollLeft}` — dimmed at the start
- Right button: `disabled={!canScrollRight}` — dimmed at the end
- Relies on shadcn `Button` disabled styles (`opacity-50 cursor-not-allowed`) for the visual effect
