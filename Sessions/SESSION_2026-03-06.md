## Phase 1 — Featured Advisors Responsive Grid

### Goal
Make the `FeaturedAdvisorsSection` carousel responsive on mobile and tablet while preserving the existing horizontal-scroll carousel layout on desktop. The original implementation forced a fixed-width horizontal scroll on all screen sizes, which looked poor on narrow devices and showed useless scroll arrows.

### `src/components/home/FeaturedAdvisorsSection.tsx`

**Grid container**
- Before: `grid grid-flow-col auto-cols-[280px] md:auto-cols-[320px] gap-6 overflow-x-auto py-2 scrollbar-hide snap-x snap-mandatory`
- After: `grid grid-cols-1 sm:grid-cols-2 lg:[grid-template-columns:none] lg:grid-flow-col lg:auto-cols-[320px] gap-4 lg:gap-6 lg:overflow-x-auto py-2 lg:scrollbar-hide lg:snap-x lg:snap-mandatory`
- Mobile (`default`): single-column stack
- Tablet (`sm`): 2-column grid
- Desktop (`lg`): resets to horizontal scroll carousel via `lg:[grid-template-columns:none]` + `lg:grid-flow-col` + `lg:auto-cols-[320px]`; overflow scroll and snap only active at `lg+`

**Scroll nav buttons (ChevronLeft / ChevronRight)**
- Wrapped in a `hidden lg:flex items-center gap-2` div
- Hidden on mobile and tablet — only shown on desktop where horizontal scroll is active
- "View All" link is outside the wrapper and remains visible at all screen sizes

## Phase 2 — Search Dropdown Z-Index Fix (Portal)

### Goal
Fix the autocomplete dropdown in `AdvisorSearchBar` appearing behind other page elements (filter chips, category pills, advisor cards) on the `/advisors` listing page.

### Root Cause
The dropdown used `z-50` but was trapped inside ancestor stacking contexts created by overflow containers, transforms, and other CSS properties on sibling/parent elements. Increasing `z-index` alone cannot escape a stacking context boundary.

### `src/components/search/AdvisorSearchBar.tsx`

**Added import:**
- `createPortal` from `react-dom`

**Added state & refs:**
- `dropdownRect: DOMRect | null` — stores the wrapper's bounding rect for positioning the portal
- `wrapperRef` — ref on the outer wrapper div to measure position

**Added effect — position tracking:**
- On `isOpen`, calls `wrapperRef.current.getBoundingClientRect()` and stores it in `dropdownRect`
- Listens to `scroll` (capture phase, all ancestors) and `resize` to keep position in sync
- Cleans up listeners on close

**Dropdown replaced with portal:**
- Rendered via `createPortal(..., document.body)` — completely outside the component DOM tree
- Uses `position: fixed` with:
  - `top: dropdownRect.bottom + 8` — just below the search bar
  - `left: dropdownRect.left`, `width: dropdownRect.width` — matches search bar width exactly
  - `zIndex: 9999` — above all page content unconditionally

## Phase 8 — Footer Layout & Visual Redesign

### Goal
Fix the cramped, visually unbalanced footer where the Services section was squeezing 18 categories into a tight 3-column sub-grid within a 2-column container, causing irregular wrapping and poor readability.

### `src/components/layout/Footer.tsx`

**Grid system:**
- Before: `grid grid-cols-2 md:grid-cols-6 gap-6 md:gap-8`
- After: `grid grid-cols-1 md:grid-cols-12 gap-10 md:gap-8`
- Switched to a 12-column grid for precise proportional control

**Brand column:**
- Before: `col-span-2 md:col-span-1`
- After: `md:col-span-3`
- Wider brand area with better breathing room; `leading-relaxed` added to tagline; `mb-5` → `mb-6`

**Services column:**
- Before: `col-span-2` with inner `grid-cols-2 sm:grid-cols-3 gap-x-4 gap-y-1.5`; links at `text-xs`
- After: `md:col-span-5` with inner `grid-cols-2 sm:grid-cols-3 gap-x-6 gap-y-2.5`; links upgraded to `text-sm`
- More horizontal space eliminates cramped wrapping; larger link text improves readability

**Explore / Support / About columns:**
- Before: Each in a standalone `<div>` as a direct grid child (col-span-1 each)
- After: Grouped inside a single `md:col-span-4` wrapper with `grid grid-cols-3 gap-6`
- Unified sub-grid ensures consistent spacing between the three link columns
- `space-y-2` → `space-y-2.5` for better vertical rhythm

**Section headings:**
- Before: `font-semibold text-sm` (plain weight, same size as links)
- After: `font-semibold text-xs uppercase tracking-widest`
- Uppercase + wide tracking creates clear visual hierarchy between headings and links

**Social icons:**
- Before: `bg-primary text-primary-foreground hover:bg-secondary hover:text-muted-foreground`
- After: `bg-primary/10 border border-primary/20 text-primary hover:bg-primary hover:text-primary-foreground transition-all duration-200`
- Subtle ring style (translucent fill + border) is more refined; hover fills to solid

**Padding:**
- Before: `py-10 md:py-14` / `mb-10`
- After: `py-12 md:py-16` / `mb-12`
- More generous vertical spacing gives the footer proper visual weight
